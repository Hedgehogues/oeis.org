OEIS · A000020

One full lap or several short ones

? Problem

GF(16) has 15 nonzero elements. Multiplying a root by itself repeatedly steps through them — some roots visit all 15, others close early.

A polynomial is primitive exactly when its root visits all 15. How many degree-4 polynomials have that property?

↓

1 One full lap, or several short ones

15 nonzero elements sit on a ring, as powers of one reference element. A root at position k steps by k each multiplication.

Left: step 1 makes one full lap — primitive. Right: step 3 closes after 5, splitting into three 5-loops — not primitive.

3a

8 elements survive — full order 15. Each root drags 3 conjugates along, so 8 survivors group into 8 / 4 = 2 polynomials.

✓ Solution

a(4) = 2
✓ verified

The same φ(2ⁿ−1)/n count, for n = 1..20 — φ grows almost as fast as 2ⁿ−1, hence the rapid climb:

a step → survives both strikes → one of φ(2ⁿ−1) full-order elements → grouped into φ(2ⁿ−1)/n polynomials
