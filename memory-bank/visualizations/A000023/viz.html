Add the even, subtract the odd

? Problem

There are 24 permutations of 4 elements. Each has some number of fixed points — positions left unmoved. Score +1 for an even count, -1 for odd, and add every score up.

The running total swings between positive and negative as n grows. What decides where it lands?
