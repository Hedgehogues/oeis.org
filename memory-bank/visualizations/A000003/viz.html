OEIS · A000003

Where the classes land

? Problem

A binary quadratic form is ax² + bxy + cy², written here as a triple (a, b, c). Three forms, all with the same discriminant b² − 4ac = −56 (so n = 14):

Two forms count as the same class if a change of variables (x,y → integer combinations, determinant 1) turns one into the other — they then represent exactly the same set of integers. How many classes are these three, really?
