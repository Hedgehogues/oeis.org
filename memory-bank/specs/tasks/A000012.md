# A000012 — the all 1's sequence

## Vision
`a(n) = 1` for every `n ≥ 0`. The values restate the definition, so this entry makes no explanatory
claim about them. The claim it carries is about the sequence's ROLE, and it is the strongest of the
four constant rows: under Dirichlet convolution this is the row whose products are the interesting
functions. Against itself it produces the number of divisors — `A000005`, the page's host — because
every term of the sum is `1` and the sum therefore counts divisor pairs. Against the identity
function it produces the sum of divisors; against Euler's totient it returns the identity function;
and it has an inverse, the Möbius function, which is Möbius inversion. That is why a row of ones
earns a place in a catalog about explaining behaviour.

## Scope
**In scope:** the `solution.mjs` / `proof.mjs` pair for A000012, the four convolution relations that
give this sequence its role, and this entry's deliberate borrowing of
`memory-bank/visualizations/A000005/viz.html`.

**Out of scope:** a page, screenshots or device records of this sequence's own — a thin entry by
decision, recorded so the absence reads as a choice. The algebra itself is specified in
`memory-bank/specs/tasks/A000005.md`. Also out of scope: the Dirichlet series of this function and
its relation to the Riemann zeta function — a real neighbour that `A000005`'s page deliberately does
not open.

## Architecture

### Overview (prose)
This sequence has no page. It borrows `memory-bank/visualizations/A000005/viz.html` and appears in
three of its frames: the worked instance at `n = 12` via
[device::DivisorPairFan](../../_terms.md#devicedivisorpairfan), where every factor pair contributes
`1 × 1` so the fan's arms count pairs and sum to `d(12) = 6`; the 4×4 table via
[device::NonClosingTable](../../_terms.md#devicenonclosingtable), where this row against itself is
one of the four cells escaping onto a function no header holds; and the Möbius-inversion frame via
[device::FixedPointOverlay](../../_terms.md#devicefixedpointoverlay), where this row combined with
`μ` is checked column by column against the identity row.

### Code
`sequences/A000012/solution.mjs` returns `1` for every `n ≥ 0` and describes no method, because there
is none. `sequences/A000012/proof.mjs` shares no code with it: it implements Dirichlet convolution
and four target functions from their own definitions (divisor count by prime factorisation, `σ` by
enumerating divisors, `φ` by counting coprimes, `μ` by squarefree factorisation), then checks the
four relations that give the sequence its role. Each relation is a sum over divisors in which this
sequence contributes a factor at every position, so a single term other than `1` would break all
four.
