# A000003 — class number of discriminant -4n

## Vision
`a(n)` counts the classes of primitive positive definite binary quadratic forms `ax²+bxy+cy²` of
discriminant `D = -4n`, where two forms are the same class exactly when an integer change of
variables of determinant 1 turns one into the other. The naive question ("how many forms of this
discriminant?") has infinitely many answers, since every class has infinitely many representative
triples. The page's central claim: classical reduction theory collapses each class down to exactly
one canonical REDUCED triple (`-a < b ≤ a ≤ c`), and mapping each reduced triple to a point
`τ = (-b+i√|D|)/(2a)` turns the algebraic finiteness of that reduction into a geometric one — every
reduced form of every discriminant lands inside one fixed region, the fundamental domain of the
modular group, so the count is something you can see rather than only compute.

## Architecture

### Overview (prose)
`memory-bank/visualizations/A000003/viz.html` runs Problem (three disguised forms of discriminant
`-56`, no visible rule for telling them apart) → (1: shrinking one of them, via
[device::MiniRecap](../../_terms.md#deviceminirecap) reused exactly as catalogued — two steps, each
reusing the previous triple and a labelled substitution arrow) → (2: the reduced-form condition
`-a<b≤a≤c`, checked against where step 1 landed) → (3: the punchline, via
[device::FundamentalDomainPlot](../../_terms.md#devicefundamentaldomainplot) — all four reduced
forms of discriminant `-56` plotted as points inside the classical fundamental domain of the
modular group) → Solution (the same plot, reused small per
[device::MiniRecap](../../_terms.md#deviceminirecap)'s own discipline, beside the count and a
verified-match badge citing `proof.mjs`'s actual run).

### Code
`sequences/A000003/solution.mjs` computes `a(n)` by exactly the procedure the page draws: enumerate
every triple `(a,b,c)` with `a ≤ √(|D|/3)` and `-a<b≤a`, keep it only if `c=(b²-D)/(4a)` is a
positive integer `≥ a`, primitive, and not the one duplicate case (`a=c`, `b<0`).
`sequences/A000003/proof.mjs` does not reuse that bounded search: it re-derives each form's validity
from the definition (discriminant, primitivity, the reduced inequalities), and separately implements
a from-scratch Gauss reduction — an iterative "shift `b` into range, swap if `c<a`" routine sharing
no code with the direct enumeration — run over a net of raw forms considerably wider than the direct
search's own bound, checking that reducing everything in that wider net recovers exactly the same
set of classes the direct search found (nothing missed, nothing duplicated), before comparing final
counts to OEIS's published terms.
