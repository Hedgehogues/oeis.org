# A000013 — necklaces, colors may be swapped, no turning over

## Vision
`a(n)` counts binary necklaces of `n` beads up to rotation and colour-complement, with reflection
explicitly excluded. The page's claim belongs to A000029: Burnside's lemma — the orbit count is the
plain average, over every element of the acting group, of how many strings that element leaves
unchanged. This entry's own contribution is showing the claim survives a group of the SAME size as
A000029's (`2n` elements) but built from different generators (rotation+complement rather than
rotation+reflection) — the averaging argument doesn't care which generators produced the group, only
that every element's fixed-string count is computed correctly.

## Architecture

### Overview (prose)
This sequence has no page of its own. Its explanation is
[device::BurnsideFixedPointTable](../../_terms.md#deviceburnsidefixedpointtable), drawn on
`memory-bank/visualizations/A000029/viz.html` for the rotation+reflection group; the identical
averaging argument, over the rotation+complement group instead (still `2n` elements, no
reflections), gives this sequence.

### Code
`sequences/A000013/solution.mjs` flood-fills every binary string's orbit under rotation and
complement only. `sequences/A000013/proof.mjs` independently checks every orbit is closed under
both moves and partitions the full state space, then re-derives the count via Burnside's lemma over
`{rotation, rotation+complement}`, computing each rotation's own explicit permutation and cycle
decomposition from scratch — a complemented rotation's fixed-string count is `2^cycles` only when
every cycle has even length, `0` otherwise — before comparing to OEIS's published terms.
