# A000004 — the zero sequence

## Vision
`a(n) = 0` for every `n ≥ 0`. The values are the definition restated, so there is no explanatory
claim to make about them and this entry does not manufacture one. The claim it does carry is about
the sequence's ROLE: under Dirichlet convolution — split `n` into every pair `d × (n/d)`, multiply
two functions across each pair, add the results — this sequence is the zero and the absorber, the
row that returns itself against every partner. That claim is drawn on `A000005`'s page, where this
sequence is one of four actors, and it is the reason a contentless list of zeros earns a place in
this catalog at all.

## Terms
MUST/MUST NOT/SHALL/SHOULD/SHOULD NOT/MAY as in RFC 2119. Uses two catalogued devices
(`../../_terms.md`), both reused unchanged and both introduced by `A000005`:
[device::NonClosingTable](../../_terms.md#devicenonclosingtable),
[device::DivisorPairFan](../../_terms.md#devicedivisorpairfan).

## Scope
**In scope:** the `solution.mjs` / `proof.mjs` pair for A000004, and this entry's deliberate
borrowing of `memory-bank/visualizations/A000005/viz.html` instead of adding a page of its own.

**Out of scope:** a page, screenshots or device records of this sequence's own — this is a thin
entry by decision, recorded here so that the absence is legible as a choice rather than an omission.
Also out of scope: the algebra itself, which is specified in
`memory-bank/specs/tasks/A000005.md`.

## Architecture

### Overview (prose)
This sequence has no page. It borrows `memory-bank/visualizations/A000005/viz.html`, which runs
Problem (four contentless rows, this one among them) → 1 (the convolution defined by one worked
instance, via [device::DivisorPairFan](../../_terms.md#devicedivisorpairfan)) → 2 (the 4×4 table
via [device::NonClosingTable](../../_terms.md#devicenonclosingtable), where this sequence's row and
column stay uniformly zero, which is what lets the four escaping cells elsewhere read as escapes) →
3 (the identity row and Möbius inversion) → Solution (the natural-number row rebuilt). This sequence
appears in frames 1 and 2 only; it has no inverse and no part in the closing construction, which is
an honest statement of its role rather than a gap.

### Code
`sequences/A000004/solution.mjs` returns `0` for every `n ≥ 0` and describes no method, because
there is none. `sequences/A000004/proof.mjs` shares no code with it: it implements Dirichlet
convolution and five partner functions from their own definitions (divisor count by prime
factorisation, `σ` by divisor sum, `φ` by coprime count, `μ` by squarefree factorisation, and the
identity function), then checks that convolving the sequence with each of them, on both sides,
returns zeros — the one property that would fail loudly if any term were wrong — plus the additive
identity property and agreement with the published terms.
