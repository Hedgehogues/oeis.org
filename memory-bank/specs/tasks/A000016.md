# A000016 — outputs of a complementing shift register

## Vision
`a(n)` counts the distinct infinite output sequences of an `n`-stage binary shift register that
feeds back the complement of its own last stage. The transition this register performs on its `2^n`
states is a bijection, so every trajectory is purely periodic; `a(n)` is exactly the number of
cycles that bijection decomposes the state space into. This is a genuinely different construction
from this catalog's necklace/bracelet family (A000029, A000011, A000013) — it complements only the
one bit shifting into the register each step, not the whole string at once — checked to diverge
from the numerically closest relative (A000013) starting at `n=6` rather than assumed related.

## Terms
MUST/MUST NOT/SHALL/SHOULD/SHOULD NOT/MAY as in RFC 2119. Uses no catalogued device — see Scope.

## Scope
**In scope:** `sequences/A000016/solution.mjs` and `proof.mjs`.

**Out of scope:** a picture. No device in `memory-bank/_terms.md` fits a general permutation's
cycle decomposition of varying-length cycles —
[device::OrbitRing](../../_terms.md#deviceorbitring)'s own General case requires every cycle
produced to be the SAME length, which this register's transition does not guarantee and does not
deliver (its 6 cycles at `n=6` have different lengths from each other). Stretching that device onto
this sequence's numbers, or inventing a new device for one entry with no genuine second use in
sight, would violate this catalog's own reuse discipline more than shipping without a picture does.

## Architecture

### Overview (prose)
No page. `sequences/A000016/solution.mjs` computes `a(n)` by simulating the register directly:
shift every bit left by one, feed back the complement of the bit that shifted out, and walk each
unvisited state until its whole cycle is marked, counting one cycle per walk.
`sequences/A000016/proof.mjs` does not reuse that walk: it independently confirms the transition is
a genuine bijection (every state has exactly one predecessor, for `n=1..16` where an `O(2^n)`
per-state check stays quick) — the fact that makes "purely periodic" true — and re-derives the same
transition on an explicit array of bits rather than solution.mjs's integer bit-shifts, cross-checked
state by state, before comparing final counts to OEIS's published terms.
