# A000007 — the characteristic function of {0}

## Vision
`a(n) = 0^n`: one `1` at `n = 0`, zeros after. The values restate the definition, so this entry
makes no explanatory claim about them. The claim it carries is about the sequence's ROLE: re-indexed
to start at `n = 1`, it is the identity element of Dirichlet convolution — combine it with any
arithmetic function and that function comes back unchanged, and no competing `0/1` pattern does the
same. That claim is drawn on `A000005`'s page, where this sequence is the identity row of the table
and the target the Möbius-inversion frame must land on. The re-indexing is a genuine subtlety and
the page states it rather than performing it silently.

## Terms
MUST/MUST NOT/SHALL/SHOULD/SHOULD NOT/MAY as in RFC 2119. Uses two catalogued devices
(`../../_terms.md`), both reused unchanged and both already on `A000005`'s page:
[device::NonClosingTable](../../_terms.md#devicenonclosingtable),
[device::FixedPointOverlay](../../_terms.md#devicefixedpointoverlay).

## Scope
**In scope:** the `solution.mjs` / `proof.mjs` pair for A000007, the offset distinction between the
published sequence (offset 0) and the identity element of the algebra (indexed from 1), and this
entry's deliberate borrowing of `memory-bank/visualizations/A000005/viz.html`.

**Out of scope:** a page, screenshots or device records of this sequence's own — a thin entry by
decision, recorded so the absence reads as a choice. The algebra itself is specified in
`memory-bank/specs/tasks/A000005.md`.

## Architecture

### Overview (prose)
This sequence has no page. It borrows `memory-bank/visualizations/A000005/viz.html`, appearing in
two of its frames: the 4×4 table via
[device::NonClosingTable](../../_terms.md#devicenonclosingtable), where this row returns every
partner unchanged and so sets the baseline against which four cells visibly escape; and the
Möbius-inversion frame via
[device::FixedPointOverlay](../../_terms.md#devicefixedpointoverlay), where the all-ones row
convolved with `μ` is checked column by column against this sequence as its target. The page labels
the re-indexed form explicitly, citing the encyclopedia's own note on this entry.

### Code
`sequences/A000007/solution.mjs` computes `a(n) = 0^n` at the published offset 0, and separately
exports the same pattern indexed from `n = 1` — the form that acts as the Dirichlet identity — so
the shift is explicit in code rather than assumed by a caller. `sequences/A000007/proof.mjs` shares
no code with it beyond those two exports: it implements convolution and six partner functions from
their own definitions (divisor count by prime factorisation, `σ` by divisor sum, `φ` by coprime
count, `μ` by squarefree factorisation, the identity function, and one arithmetic-meaningless
irregular function), verifies the identity property on both sides for all of them, and then requires
five competing `0/1` patterns to fail that same property.
