# A000008 — ways of making change for n cents

## Vision
`a(n)` counts the piles of 1-, 2-, 5- and 10-cent coins (unlimited supply, order irrelevant) that
sum to `n` cents. The naive question ("how many combinations?") gives no handle on why the count
grows the way it does from one `n` to the next. The page's central claim: building the count up one
coin denomination at a time makes every jump traceable — the count for a fixed amount after adding
a new coin equals what it already was (no new coin used) plus the count for that amount minus the
new coin's value (one more copy of the new coin appended to an existing way), a recurrence that is
directly checkable cell by cell rather than asserted about the final total alone.

## Terms
MUST/MUST NOT/SHALL/SHOULD/SHOULD NOT/MAY as in RFC 2119. Uses one catalogued device, new to the
catalog: [device::IncrementalTally](../../_terms.md#deviceincrementaltally).

## Architecture

### Overview (prose)
`memory-bank/visualizations/A000008/viz.html` runs Problem (the four coin denominations, "how many
piles make 7 cents?") → (1: the full staged table for amounts 0–7, one row per denomination added,
via [device::IncrementalTally](../../_terms.md#deviceincrementaltally)) → (2: one cell zoomed in —
the count for 7 after allowing 2-cent coins splits into its two source cells, highlighted and
summed, via the same device) → Solution (all 6 concrete coin piles for `n=7`, beside the count and
a verified-match badge citing `proof.mjs`'s actual run).

### Code
`sequences/A000008/solution.mjs` computes `a(n)` by exactly the procedure the page draws: the
standard unbounded-knapsack recurrence, staged one denomination at a time, exporting the full stage
history so the page can render every row rather than only the final one.
`sequences/A000008/proof.mjs` does not reuse that recurrence: it independently counts, by direct
triple-nested enumeration over coin quantities, every quadruple `(c1,c2,c5,c10)` of non-negative
coin counts satisfying `c1+2c2+5c5+10c10=n` — the definition read literally, sharing no code with
the staged DP — before comparing final counts to OEIS's published terms.
