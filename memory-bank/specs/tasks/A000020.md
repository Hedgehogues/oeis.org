# A000020 — primitive polynomials of degree n over GF(2)

## Vision
`a(n)` counts the degree-`n` monic polynomials over `GF(2)` whose root is a PRIMITIVE element of
`GF(2ⁿ)` — one that generates the entire multiplicative group of `2ⁿ - 1` nonzero elements, rather
than only a subgroup. The naive question ("which of these roots is special?") gives no handle on
the count. The page's central claim: arranging the group's elements on a ring by a fixed reference
generator turns "does this root's repeated multiplication visit everything?" into "does its step
size share no factor with `2ⁿ-1`?" — the identical sieve `A000010`'s page already draws, run
against the group order instead of `n` itself, then divided by `n` for the conjugate roots each
polynomial contributes.

## Architecture

### Overview (prose)
`memory-bank/visualizations/A000020/viz.html` runs Problem (`GF(16)`'s 15 nonzero elements; which
roots visit all 15 under repeated multiplication?) → (1: via
[device::OrbitRing](../../_terms.md#deviceorbitring), step 1 traces one full 15-ring, step 3 splits
into three 5-rings) → (2: via [device::TotientSieveStrip](../../_terms.md#devicetotientsievestrip),
sieving step sizes `1..15` for survivors coprime to 15) → (3: 8 survivors, 4 conjugate roots per
degree-4 polynomial, `8/4=2` primitive polynomials) → Solution (`a(4)=2`, the same `φ(2ⁿ-1)/n` count
charted for `n=1..20`, a verified-match badge that states the `a(1)` exception plainly).

### Code
`sequences/A000020/solution.mjs` computes `a(n)` by direct enumeration: test every monic degree-`n`
polynomial for irreducibility (trial division against lower-degree candidates), then test whether
its root's multiplicative order equals `2ⁿ-1` exactly. `sequences/A000020/proof.mjs` re-derives this
with an independently-written irreducibility test and order routine sharing no code with
`solution.mjs`, and separately computes the standard closed form `φ(2ⁿ-1)/n` via trial-division
factorization of the group order — a structurally different computation entirely — before comparing
to OEIS's published terms.
