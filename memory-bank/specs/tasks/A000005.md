# A000005 — d(n), the number of divisors of n

## Vision
`a(n)` is the number of divisors of `n`. Counting them is not itself mysterious, so a page that only
counted would have nothing to explain. The page's central claim is the one that makes `d(n)`
inevitable rather than merely defined: there is a single operation on arithmetic functions — split
`n` into every pair `d × (n/d)`, multiply the two functions across each pair, add the results — and
under that operation the four sequences whose own values are trivial (`A000004` all zeros, `A000007`
a 1 then zeros, `A000012` all ones, `A000027` the natural numbers) are its zero, its identity, and
two ordinary members. Combining them does not stay inside that set: four of the sixteen products
land on `d(n)`, `σ(n)` and `n·d(n)`. `d(n)` is what the all-ones row produces against itself, and
that non-closure is why four apparently contentless entries earn their place — they are the
constants of an algebra whose products are the interesting functions.

## Scope
**In scope:** `memory-bank/visualizations/A000005/viz.html` — the current, only page for this
sequence (no kept drafts) — the `solution.mjs` / `proof.mjs` pair, and the algebraic relations the
page draws, which later thin entries for A000004, A000007, A000012 and A000027 are expected to
reference rather than redraw.

**Out of scope:** the devices' own quality requirements (`../../specs/approaches.md`,
`../../specs/visualizations.md`); Dirichlet series, the Riemann zeta function, and multiplicativity
of `d(n)` — real neighbours of this material that the page deliberately does not open.

## Architecture

### Overview (prose)
`memory-bank/visualizations/A000005/viz.html` runs Problem (the four constant rows written out, with
nothing to predict) → (1: the operation defined by one worked instance at `n = 12`, via
[device::DivisorPairFan](../../_terms.md#devicedivisorpairfan), whose six factor pairs sum to
`d(12) = 6`) → (2: the same operation tabulated over all four rows, via
[device::NonClosingTable](../../_terms.md#devicenonclosingtable), with the escaping cells marked and
named) → (3: the identity row shown leaving three different partners unchanged, then Möbius
inversion via [device::FixedPointOverlay](../../_terms.md#devicefixedpointoverlay) reused as
catalogued — the all-ones row combined with the Möbius function, checked column by column against
the identity row) → Solution (the natural-number row rebuilt from the others: the twelve fractions
`k/12` in lowest terms bucketed by denominator, bucket sizes `φ(d)` summing back to 12, closed by
[device::MiniRecap](../../_terms.md#deviceminirecap) bringing the Problem's own rows back small).

### Code
`sequences/A000005/solution.mjs` computes `a(n)` as the number of divisor pairs of `n`, found by
trial division up to `√n` — the constant-1 case of the very convolution the page defines — and
exports that convolution along with the Möbius function and Euler's totient, each written from its
own definition, because the page's later frames run the same operation on them.
`sequences/A000005/proof.mjs` reuses none of it: it recomputes `d(n)` from the prime factorisation
as the product of each exponent plus one, brings its own deliberately slow divisor enumeration and
its own convolution, re-derives every relation the page draws against independently computed targets
(σ from its own divisor sum, φ from its own coprime count), verifies commutativity and associativity
on every triple of the cast, checks the non-closure claim as a fact rather than accepting the
caption, and only then compares the counts to OEIS's published terms.
