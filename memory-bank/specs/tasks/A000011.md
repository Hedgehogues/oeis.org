# A000011 — necklaces where complements are equivalent

## Vision
`a(n)` counts binary necklaces of `n` beads up to rotation, reflection AND colour-complement — the
same "how many distinct colorings" question A000029 asks, over a larger group. The page's claim
belongs to A000029: Burnside's lemma — the orbit count is the plain average, over every element of
the acting group, of how many strings that element leaves unchanged. This entry's own contribution
is showing that claim survives a genuinely larger, differently-structured group (rotations and
reflections, each either plain or paired with a global colour-complement) without needing a new
argument.

## Architecture

### Overview (prose)
This sequence has no page of its own. Its explanation is
[device::BurnsideFixedPointTable](../../_terms.md#deviceburnsidefixedpointtable), drawn on
`memory-bank/visualizations/A000029/viz.html` for the plain rotation+reflection group; the
identical averaging argument, over the rotation+reflection+complement group (`4n` elements instead
of `2n`), gives this sequence.

### Code
`sequences/A000011/solution.mjs` flood-fills every binary string's orbit under rotation, reflection
AND complement — A000029's method with complement added as a third generator.
`sequences/A000011/proof.mjs` independently checks every orbit is closed under all three moves and
partitions the full state space, then re-derives the count via Burnside's lemma over the full
`4n`-element group, computing each element's own explicit permutation and cycle decomposition from
scratch — a complemented element's fixed-string count is `2^cycles` only when every cycle has even
length, `0` otherwise — before comparing to OEIS's published terms.
