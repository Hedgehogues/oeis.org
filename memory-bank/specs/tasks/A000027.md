# A000027 — the positive integers

## Vision
`a(n) = n`. The values are the definition restated, so this entry makes no explanatory claim about
them. The claim it carries is about the sequence's ROLE, and it is the busiest of the four constant
rows: under Dirichlet convolution this sequence produces the sum of divisors when combined with the
all-1s row, produces Euler's totient when combined with the Möbius function, and — the closing frame
of `A000005`'s page — is itself REBUILT by the totients of its own divisors, which add up to `n`.
A row that looks like the least interesting object in the catalog turns out to be what the page's
argument produces at the end.

## Architecture

### Overview (prose)
This sequence has no page. It borrows `memory-bank/visualizations/A000005/viz.html` and appears in
its 4×4 table via [device::NonClosingTable](../../_terms.md#devicenonclosingtable) — as the source
of two of the four cells that escape, onto `σ(n)` and onto `n·d(n)` — and again in the closing
frame, where the `n` fractions `k/n` are bucketed by reduced denominator, the buckets labelled with
[device::DivisorChips](../../_terms.md#devicedivisorchips) and the row itself returning redrawn
small via [device::MiniRecap](../../_terms.md#deviceminirecap). The close rebuilds this sequence
rather than restating it.

### Code
`sequences/A000027/solution.mjs` returns `n` and describes no method, because there is none.
`sequences/A000027/proof.mjs` shares no code with it: it implements Dirichlet convolution and three
target functions from their own definitions (`σ` by enumerating divisors, `φ` by counting coprimes,
`μ` by squarefree factorisation), checks the three relations, and then checks the ARGUMENT behind
the third rather than only its conclusion — for every `n`, the `n` fractions `k/n` reduced to lowest
terms must bucket by denominator `d` into groups of exactly `φ(d)`, together accounting for all `n`
fractions. A correct total reached by wrong buckets fails that check.
